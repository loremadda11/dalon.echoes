# Dalon Echoes

An unfinished personal website experiment created as a home for artistic projects, music and visual ideas.

The project was built with Astro as a lightweight creative portfolio / archive. It currently includes an initial landing page for music, thoughts and links, but it is not an active or finished product.

## Why this repository exists

I created Dalon Echoes as a place where different creative interests could live together rather than as a conventional software project. The idea was to use the website as a container for music, visual experiments and short written reflections.

## Status

**Paused / experimental.**

The repository is kept as part of my creative work and may be revisited in the future.

## Stack

- Astro
- HTML / CSS
- JavaScript ecosystem
